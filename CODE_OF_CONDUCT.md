# Code de conduite

Nous voulons un espace technique sûr, précis et accueillant.

- critiquez les idées et les changements, pas les personnes ;
- supposez une intention constructive tout en demandant des preuves ;
- évitez harcèlement, discrimination, intimidation et contenu sexuel non voulu ;
- respectez la confidentialité des rapports de sécurité et des utilisateurs ;
- n'utilisez jamais des données de chat réelles sans consentement et nécessité ;
- acceptez les décisions de modération et corrigez rapidement un comportement
  signalé.

Les mainteneurs peuvent modifier ou retirer une contribution, limiter une
interaction ou exclure une personne pour protéger le projet. Signalez un
incident par le canal privé décrit dans `SECURITY.md`; n'exposez pas la personne
concernée dans une issue publique.
